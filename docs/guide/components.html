Concept 03组件 API

两套组件树加一个 Provider。每个组件渲染固定标签、固定 class 与 data 属性，遍历交给作用域插槽。

v-slotChatContentThreadList
01

AuiRuntimeProvider

App.vue
<AuiRuntimeProvider :adapter="adapter" :tools="tools">
    <!-- 子树 -->
</AuiRuntimeProvider>
属性类型必填说明
adapter{ ChatTransport, MessageHistory, ThreadList }是三套适配器实例。
toolsTool[]否前端工具列表，见 前端工具。

Provider 只装配一次，不同 Provider 各有独立 store 与 AuiPage，可并排两个互不干扰。

02

ChatContent 组件树

tree
ChatContent.Root                div    聊天区域根容器
├── ChatContent.Viewport         div    滚动视口（自动滚到底）
│   └── ChatContent.Messages     div    遍历消息，v-slot="{ message }"
│       └── ChatContent.Parts    span   遍历片段，v-slot="{ part }"
└── ChatContent.Composer.Root    form   输入区（阻止默认提交）
    ├── ChatContent.Composer.Input  textarea
    └── ChatContent.Composer.Send   button
组件要点
Messages对 store.messages 逐条渲染，插槽作用域 { message }。
Parts对当前消息的 parts 逐个渲染，作用域 { part }；渲染为 span，方便内联拼装。
Viewport只在内容溢出时滚到底，不会打断用户上滑。
Composer.Input受控 textarea，支持 Cmd/Ctrl + Enter 发送。
Composer.Send执行中自动 disabled。
Composer.Root渲染 form，自动阻止默认提交。

两层插槽把"消息"和"片段"的遍历都替你做完了，模板里只需要判类型：

Messages.vue
<ChatContent.Messages v-slot="{ message }">
    <div :data-role="message.role">
        <ChatContent.Parts v-slot="{ part }">
            <p v-if="part.type === 'text'">{{ part.text }}</p>
            <p v-else-if="part.type === 'loading'" class="hint">{{ part.text }}</p>
            <details v-else-if="part.type === 'thinking'">
                <summary>思考过程</summary><p>{{ part.text }}</p>
            </details>
            <ToolCallCard v-else-if="part.type === 'tool-call'" :part="part" />
        </ChatContent.Parts>
    </div>
</ChatContent.Messages>
先收窄再访问。tool-call 分支没有 text 字段， 直接写 part.text 会在工具调用时拿到 undefined。
03

ThreadList 组件树

tree
ThreadList.Root                 div     列表根容器
├── ThreadList.New              button  新建会话
└── ThreadList.Items            div     遍历会话，v-slot="{ thread }"
    └── ThreadList.Item.Root     div     单条容器（带 data-status / data-active）
        ├── ThreadList.Item.Trigger  button  切换会话（归档态不可点）
        │   └── ThreadList.Item.Title span   会话标题
        ├── ThreadList.Item.Archive  button
        ├── ThreadList.Item.UnArchive button
        └── ThreadList.Item.Delete   button
组件要点
Item.Rootdata-status="regular|archived"；激活时出现 data-active（无值）。
Item.Trigger归档会话不会被激活，需先取消归档。
Item.Title渲染 thread.title，缺省回退「新会话」；也可以传插槽内容自定义。
Archive归档当前会话时，界面自动进入新建会话状态。
UnArchive恢复为 regular，不会自动切换进该会话。
Delete删当前会话时自动进入新建会话状态。

样式钩子

节点classdata 属性
ChatContent.Rootaui-chat-content-root—
Viewport / Messages / Parts-viewport / -messages / -partsMessages 外层带 data-role
Composer 三件aui-composer-root / -input / -sendSend 执行中带 data-disabled
ThreadList 树aui-thread-list-root / -new / -items—
Item 系列aui-item-root / -trigger / -title / -archive / -unarchive / -deletedata-status / data-active

整份 class 名以 aui- 打头，不会与任何设计系统的命名冲突。
