Guide 01安装与接入

装包、写三套适配器、挂 Provider —— 三步之后你就有了一套能用的对话界面骨架，样式待你填。

vue 0.1.0Vue 3@auipage/core 0.1.0
01

环境与依赖

组件是纯 Vue 3 实现，运行时由 @auipage/core 提供，装 @auipage/vue 时会自动带上。

依赖版本作用
vue^3.4.34组件宿主框架，用 defineComponent + h 渲染，不依赖模板编译器。
@auipage/core^0.1.0编排器 AuiPage、适配器基类与 generator。

库里没有 CSS 文件，也不需要引入任何样式资源。

02

安装

terminal
npm install @auipage/vue
03

三步接入

第一步：适配器。三个实例按固定 key 装进一个对象。

adapter.ts
import {
    ChatTransportAdapter,
    MessageHistoryAdapter,
    ThreadListAdapter,
} from "@auipage/vue";

export default {
    ChatTransport: new ChatTransportAdapter({ /* run / response */ }),
    MessageHistory: new MessageHistoryAdapter({ /* load / append */ }),
    ThreadList: new ThreadListAdapter({ /* list / new / archive / ... */ }),
};

第二步：Provider。挂载时它会立刻调用一次 ThreadList.list()。

App.vue
<script setup>
import { AuiRuntimeProvider, ChatContent, ThreadList } from "@auipage/vue";
import adapter from "./adapter";
</script>

<template>
    <AuiRuntimeProvider :adapter="adapter" :tools="tools">
        <!-- ChatContent / ThreadList -->
    </AuiRuntimeProvider>
</template>

第三步：搭界面。组件是命名空间对象，模板里按层级组合；样式通过 class 钩子接管。

细节见 适配器、组件 API、 前端工具、数据流与状态。

04

不打包，直接引用

IIFE 构建通过全局 Vue 使用 Vue，库本身的全局名是 AuipageVue。先加载 Vue，再加载本库：

index.html
<script src="https://unpkg.com/vue@3.4.34/dist/vue.global.prod.js"><\/script>
<script src="https://unpkg.com/@auipage/vue@latest/dist/auipage-vue.iife.js"><\/script>

<script>
    const { AuiRuntimeProvider, ChatContent, ThreadList } = AuipageVue;
    Vue.createApp({ /* ... */ }).mount("#app");
<\/script>
顺序不能反。Vue 必须先于本库加载。打包器环境（Vite / webpack）会处理依赖，不需要手动加载全局脚本。
05

本地跑起来

仓库自带 playground 与 mock 服务，oipage-cli 同时起 mock（30000）与 vite（20000）：

terminal
npm run dev
# http://localhost:20000/

mock 里预置了会话与历史消息，切换会话能看到渲染；发送消息默认接本地 ollama。
