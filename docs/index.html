01

三个设计取向

Headless

只给状态和钩子

每个组件渲染固定标签，挂稳定的 aui-* class 与 data-* 属性， 没有一行内置 CSS —— 风格问题永远不会变成库的问题。

Slot

作用域插槽，不是配置

Messages 给你 { message }、Parts 给你 { part }， 模板里 v-if 收窄类型，想渲染什么就是你自己的模板。

Adapter

后端无关

三套适配器把 HTTP、SSE、WebSocket 挡在库外，换模型、换服务端只改适配器， 组件树一行不动。

02

组件总览

组件渲染标签作用
ChatContent.Rootdiv聊天区域根容器
ChatContent.Viewportdiv滚动视口，新消息与流式增量自动滚到底
ChatContent.Messagesdiv遍历消息，提供 { message } 插槽
ChatContent.Partsspan遍历片段，提供 { part } 插槽
Composer.Root / Input / Sendform / textarea / button输入区三件，执行中自动禁用发送
ThreadList.*div / button / span会话的新建、切换、归档、删除

04

最小骨架

App.vue
<template>
    <AuiRuntimeProvider :adapter="adapter" :tools="tools">
        <ThreadList.Root>
            <ThreadList.New>新建会话</ThreadList.New>
            <ThreadList.Items v-slot="{ thread }">
                <ThreadList.Item.Root>
                    <ThreadList.Item.Trigger>
                        <ThreadList.Item.Title />
                    </ThreadList.Item.Trigger>
                </ThreadList.Item.Root>
            </ThreadList.Items>
        </ThreadList.Root>

        <ChatContent.Root>
            <ChatContent.Viewport>
                <ChatContent.Messages v-slot>
                    <ChatContent.Parts v-slot="{ part }">
                        <p v-if="part.type === 'text'">{{ part.text }}</p>
                        <p v-else-if="part.type === 'thinking'">{{ part.text }}</p>
                    </ChatContent.Parts>
                </ChatContent.Messages>
            </ChatContent.Viewport>
            <ChatContent.Composer.Root>
                <ChatContent.Composer.Input />
                <ChatContent.Composer.Send>发送</ChatContent.Composer.Send>
            </ChatContent.Composer.Root>
        </ChatContent.Root>
    </AuiRuntimeProvider>
</template>
