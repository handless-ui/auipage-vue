Concept 02适配器

组件库不发任何网络请求，也不绑定模型。三个适配器是它与你的后端之间唯一的接缝：你实现接口，它在合适的时机调用。

ChatTransportAdapterMessageHistoryAdapterThreadListAdapter
01

总览

适配器职责需要实现
ChatTransportAdapter发起一轮对话，流式产出片段run / response
MessageHistoryAdapter历史消息的加载与入库load / append
ThreadListAdapter会话列表的增删改查list / new / archive / unarchive / delete

三个实例装进一个对象，key 名固定：

adapter.ts
export default { ChatTransport, MessageHistory, ThreadList };
02

ChatTransport：流式对话

chatTransport.ts
new ChatTransportAdapter({
    async *run({ messages, context }) {
        // messages        本轮新发送的消息
        // context.history 已入库的历史消息组
        // context.tools   注册的前端工具描述
    },
    response(name, data) { /* 工具结果回传 */ },
});
字段类型说明
run(params) => AsyncGenerator<ContentPart>逐个 yield 片段；返回假值时本轮直接结束。
response(name, data) => unknown反向通道，用于 response("tool-result", { id, status, result })。

回调式流读（fetch / WebSocket）用 generator 包一层即可：

chatTransport.ts
import { ChatTransportAdapter, generator } from "@auipage/vue";
import { fetch } from "@auipage/fetch";

new ChatTransportAdapter({
    async *run({ messages, context }) {
        yield { type: "loading", text: "思考中..." };

        yield* generator((push, end, error) => {
            fetch({ url: "/api/chat", method: "POST", body: JSON.stringify({ messages, tools: context.tools }) })
                .then(res => {
                    res.on("data", chunk => push(JSON.parse(chunk)));
                    res.on("end", end);
                    res.on("error", error);
                })
                .catch(error);
        });
    },
});
03

MessageHistory：历史读写

messageHistory.ts
new MessageHistoryAdapter({
    async load(threadId) { /* HistoryMessageGroup[] */ },
    async append(threadId, group) { /* void */ },
});
  • load 在切换会话时调用，返回假值时跳过历史加载。
  • append 每轮结束写入一整组消息，与 run 收到的结构同构。
  • loading 片段不用手动剔除，渲染历史时会自动过滤。
04

ThreadList：会话管理

threadList.ts
new ThreadListAdapter({
    async list() {},                    // Thread[]
    async new(firstGroup) {},           // Thread | void
    async archive(threadId) {},
    async unarchive(threadId) {},
    async delete(threadId) {},
});
方法时机与行为
listProvider 挂载时调用一次。
new新会话发送第一条消息时调用；返回假值会中止本轮后续流程。
archive归档；归档的是当前会话时自动回到新建态。
unarchive取消归档，不自动切换会话。
delete删除；删的是当前会话时自动回到新建态。

会话对象的最小约定：

types.ts
interface ThreadListItem {
    threadId: string;                 // 必填，列表 key 与操作都靠它
    title: string;
    status: "regular" | "archived";
}
threadId 是列表的 key。新会话会 unshift 到列表头部，没有稳定 key 时 Vue 按位置复用组件，会出现数据错位。
05

片段数据形态

part
{ type: "text",      text: "正文增量" }
{ type: "thinking",   text: "思维链增量" }
{ type: "loading",    text: "思考中..." }
{
    type: "tool-call",
    id: "call-xxx",     // 稳定 key，phase 原地切换
    name: "askFavoriteFruit",
    args: {},
    phase: "pending",   // pending → executing → result
    status: "pending",  // pending / success / error
    result: {}
}

文本类片段是增量拼接的：同 role 的连续片段并入同一条消息， 同类型的连续片段并入同一个 part 的 text，DOM 上是一段文字在变长，而不是不断新建节点。

业务也可以 yield 任意带 type 的对象，运行时会原样放进 parts， 由你的 Parts 插槽决定怎么渲染。
